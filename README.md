# Living Brain CLI

The official command-line interface for the [Living Brain](https://livingbrain.com) API.

## Documentation

- **API reference and guides:** https://livingbrain.ferndocs.com
- **CLI guide:** https://livingbrain.ferndocs.com/sdk/cli

## Generated code

This CLI is generated by [Fern](https://buildwithfern.com) from the Living Brain OpenAPI
spec. Source of truth lives in
[fern-demo/livingbrain-config](https://github.com/fern-demo/livingbrain-config) — open
changes there, not here, or they'll be overwritten on the next generation.
